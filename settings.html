How translation works

Saving a connection does not enable translation. Return to the conversation and choose OpenAI-compatible API as the translation engine.

When enabled, message text goes to your chosen endpoint. A local oMLX endpoint processes requests on this computer; remote providers apply their own usage and retention policies.

Profiles adapt instructions and roles for the selected model family. Your API server applies the actual model chat template. Automatic detection uses the model ID; use an override for aliases.

The sample test checks connectivity and the expected output format. Translation quality still depends on the model, its version, and your conversations.

Settings and API keys are stored in an ignored local file with owner-only permissions. Keys are never returned to this page.
